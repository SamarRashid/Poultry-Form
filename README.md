# H Suleman Layer Farm — Dashboard

A modern, responsive poultry and layer farm management dashboard built with Next.js, React, Tailwind CSS, TypeScript, and Recharts.

## Features

- **Daily Egg Production Analytics**: 7-day and 30-day collection curves, shed breakdown, and collection efficiency rates.
- **Active Bird Tracking**: Live count of active layer flocks excluding mortality and culled birds.
- **Feed Inventory & Threshold Monitoring**: Real-time stock levels of Maize, Soybean Meal, Rice Bran, and Layer Mash with automated minimum buffer alerts.
- **Feed Consumption Logging**: Daily ration distribution tracking across sheds.
- **Operational Expense Ledger**: Routine expenses, backup generator fuel, and medicine costs in PKR.
- **Cash Movement Overview**: Daily egg sale receipts and disbursements.
- **Quick Logging Shortcuts**: Fast operational entries for shed managers.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Visualizations**: Recharts

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

To produce an optimized production build:
```bash
npm run build
```
